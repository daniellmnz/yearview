Install with the MSI; it upgrades in place over any earlier version and keeps
your settings.

This release carries the v3.7.5 changes as well, which were built but not
published.

**New — the status line can be turned off, and now is by default.**

The line under the year — when the page was generated, the mailbox it was read
from, the number of items, how long Outlook took, and the version — is useful
while something is being looked into, and less welcome the rest of the time,
because it names the mailbox on a page that often ends up on a shared screen
or in a printout.

There is now a **Show status line** checkbox with the other display options in
**⚙ Settings**. It is **off by default**, so after upgrading the line will be
gone until you switch it on. The change takes effect at once, and is
remembered.

Turned off, the line is not written into the page at all rather than hidden.
That is deliberate, and it is the lesson of 3.7.4: text that is merely
invisible still prints into a PDF and can be copied out of it. With the line
off there is nothing in the page to reveal.

**New — the version is shown at the foot of the Settings panel.**

With the status line off, the version would otherwise appear nowhere. It is
now always available in **⚙ Settings**, and is stamped into the page from the
single place the version is defined, so it cannot disagree with the build.

**On upgrading**

The calendar reader is unchanged in this release, so there is no startup
validation to re-earn.
